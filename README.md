# Tic Tac Toe

A responsive two-player tic-tac-toe game built with React and Vite.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

## Features

- Two-player turn-based gameplay with accessible board controls
- Win and draw detection with highlighted winning squares
- Match scoreboard, new-round action, and full reset
- Responsive layout for desktop and mobile
